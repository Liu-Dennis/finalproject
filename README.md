We made a artist protfolio creator that users can link wherever they would like to showcase their art. The app allows users to post images on their page and organize them by priority, the higher the priority the higher the post is on their page. The user is also able to add a artist statement or description on the post that shows when the post is clicked by a viewer which shows the full image and its title. When signed in a user is able to view their page like a visitor would with by swapping between viewing and editing modes. The user page also has a manage files option that allows a user to view what files they have up and delete or download them.

We used express for the server side and mongoDB for the database similar to the previous assignments. We wrote our site in react bootstrap with javascript for the server and css for some of the styling where bootstrap was insufficient.
